# Контакт — каталог распиновок AV

Мобильный русскоязычный справочник: 37 карточек распространённых разъёмов, вариантов стандартов и переходников. Поиск по названиям и сигналам, категории, избранное, светлая/тёмная тема, ссылки на карточки, офлайн-кэш. Крупные иллюстрации внешнего вида и цветовые обозначения жил для Ethernet, DMX по витой паре, IEC-питания и распространённой схемы USB 2.0.

Статический сайт без сборки, зависимостей, регистрации и аналитики. Откройте `index.html` или запустите `python3 -m http.server 8080`. Service Worker и копирование ссылок требуют HTTPS либо localhost. После первой успешной загрузки кэша сайт работает без сети.

## Состав

- Аудио: XLR 3, TRS балансный/стерео, TS, TRRS CTIA/OMTP, RCA, speakON NL2/NL4/NL8.
- Видео: HDMI Type A, DisplayPort, VGA, DVI, BNC/SDI, RCA CVBS, S-Video.
- Свет: DMX XLR 3/5 и RJ45.
- Сеть: RJ45 T568A/T568B.
- Данные: USB 2.0 A/B/Mini-B/Micro-B, USB-C (гнездо).
- Управление: MIDI DIN/TRS A/B, RS-232 DE-9/DB25 (основные линии).
- Питание: powerCON A/B и TRUE1.
- Переходники: XLR–TRS, DMX 3–5, RJ45 crossover 10/100.

Это каталог распространённых AV-интерфейсов, а не всех существующих разъёмов. Фирменные распиновки всегда проверяются по документации конкретного устройства. В каждой карточке указана ссылка на источник. Карты контактов явно отличаются от физических схем: не используйте расположение блоков карты для определения геометрии контактов.

## Редактирование

База — `data.js`. Для удобства исходные данные описаны в `create_data.py`; после изменения запустите `python3 create_data.py`. Иллюстрации — оригинальные SVG в `images/`; генератор `build_illustrations.py` не требует зависимостей. Все картинки включены в офлайн-кэш. Интерфейс — `app.js`, стили — `style.css`. При обновлении ресурсов меняйте версию `CACHE` в `sw.js`.

## GitHub Pages

Сайт публикуется из корня ветки `main`. `.nojekyll` отключает обработку Jekyll. Никакие серверные API не нужны.

Идея мобильного справочника вдохновлена AV Tools; интерфейс, тексты и графика созданы независимо. Документация производителей остаётся собственностью правообладателей; используются ссылки и фактические назначения контактов.
